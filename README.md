# NoteForge

**一个无需时刻在线的 Markdown 笔记网页。**

基于浏览器 PWA：首次访问后即可**完全离线使用**，无需安装客户端、无需登录、无需服务器；手机、平板、电脑打开即用，界面自动适配屏幕。

- **版本：** V2
- **使用访问：** https://ll9-m.github.io/NoteForge/

## 已实现功能

### 笔记与科目

| 功能 | 说明 |
|------|------|
| 科目管理 | 新建、重命名、删除科目；桌面端拖拽排序；单个删除与批量多选删除 |
| 笔记管理 | 新建、编辑、删除；按更新时间自动排序 |
| 批量操作 | 多选笔记 / 科目，支持全选、批量移动到其他科目、批量删除 |
| 侧边栏 | 桌面端可收起，移动端抽屉式展开，收起状态自动记忆不丢失 |
| 笔记模板 | 新建笔记自动套用模板，支持 `{{date}}`、`{{title}}` 变量，可在「⋮ → 笔记模板」中自定义 |
| 默认科目 | 可设置打开应用时默认进入的科目 |

### Markdown 编辑与预览

| 功能 | 说明 |
|------|------|
| 分栏编辑 | 电脑端左编辑右预览，**双向同步滚动**；手机端一键切换编辑 / 预览 |
| 格式化工具栏 | 13 个工具：标题、加粗、斜体、删除线、链接/图片、无序/有序/任务列表、表格、引用、代码块、撤销、重做 |
| 两种工具栏形态 | 顶栏横向长栏（窗口变窄自动收缩）／悬浮 Tab 圆盘（滚轮翻页、长按拖拽换位置），「⋮ → 工具栏设置」切换 |
| 自定义快捷键 | 每个工具可单独设置组合键，预览模式下按快捷键自动切入编辑 |
| 代码高亮 | 内置 highlight.js，**离线可用**，高亮结果带缓存 |
| 任务列表 | 预览区点击勾选框直接回写 Markdown 源文件 |
| 图片插入 | 图片存入本地数据库（IndexedDB），导出时自动打包，跨设备迁移不丢图 |

### 图片查看（新增）

预览区点击任意图片进入灯箱：

- 滚轮 / 双指捏合缩放（25%–800%，以指针为锚点）、拖拽平移、双击复位
- 一键**下载**原图（本地图片保留原始文件名；外链图片取不到时自动新标签打开）
- `Esc` 关闭，`+ / - / 0` 调整缩放，`Ctrl+S` 下载

### 数据与离线

| 功能 | 说明 |
|------|------|
| 导出 | 勾选任意科目 / 笔记导出为 zip：纯 Markdown 文件 + 图片 + `noteforge.json` 元数据，任何编辑器都能打开 |
| 导入 | 支持官方备份包，也支持按 `<科目>/md/*.md`、`<科目>/img/*` 目录结构手动打包导入 |
| 冲突策略 | 导入遇重复时可选：保留最新版本 / 全部覆盖 / 跳过重复 |
| PWA 离线 | Service Worker 首次访问即缓存全部资源，断网照常使用 |
| 安装到桌面 | 手机、电脑均可「添加到主屏幕」，独立窗口运行 |
| 恢复出厂 | 一键清空全部数据（会先提醒导出备份） |

### 外观与主题

- **四个主题**：跟随系统 / 浅色 / 深色 / **液态玻璃**（静态彩色光晕背景 + 毛玻璃表面，无持续动画，低配设备不掉帧）
- 字体大小 12–24px 可调
- 桌面 / 移动自适应布局，移动端工具栏自动贴合软键盘

### 内置内容

- **必读文件**：首次打开自动写入「必读」科目与《使用说明与 Markdown 速查》笔记，包含 Markdown 语法速查表
- **默认笔记模板**：新建笔记自带「一句话总结 / 笔记 / 复习记录 / 实践 / 参考」结构，可自行修改

## 快速开始

1. 下载或克隆本仓库
2. 用任意静态服务器打开（或直接双击 `index.html`）
3. 开始记笔记

> Service Worker 需要 `http(s)://` 或 `localhost` 才会生效；`file://` 直接打开仍可正常使用，只是没有离线缓存和安装能力。

### 部署到 GitHub Pages

1. Fork 本仓库
2. 进入 Settings → Pages
3. Source 选择 `main` 分支，根目录 `/`
4. 保存后访问 `https://<你的用户名>.github.io/NoteForge/`

## 数据说明

- 所有数据保存在浏览器 **IndexedDB** 中，不上传任何服务器
- **清理浏览器数据会丢失笔记**，请定期用「⋮ → 导出数据」备份
- 导出的 zip 内是纯 Markdown，可用任何编辑器打开、可长期归档

## 键盘快捷键

| 操作 | 快捷键（默认，均可自定义） |
|------|--------|
| 标题 | `Ctrl+1` |
| 加粗 / 倾斜 / 删除线 | `Ctrl+B` / `Ctrl+I` / `Ctrl+D` |
| 链接 / 图片 | `Ctrl+K` |
| 无序 / 有序 / 任务列表 | `Ctrl+Shift+U` / `Ctrl+Shift+O` / `Ctrl+Shift+T` |
| 表格 / 引用 / 代码块 | `Ctrl+Shift+C` / `Ctrl+Shift+Q` / `Ctrl+Shift+E` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 灯箱缩放 / 复位 / 下载 | `+` `-` / `0` / `Ctrl+S`（`Esc` 关闭） |

自定义入口：`⋮ → 工具栏设置 → 快捷键设置`（点击输入框后直接按键录入）。

## 技术栈

- 纯 HTML + CSS + JavaScript，**无构建工具、无框架**
- IndexedDB 本地存储
- [marked.js](https://github.com/markedjs/marked) — Markdown 渲染
- [highlight.js](https://github.com/highlightjs/highlight.js) — 代码高亮
- [fflate](https://github.com/101arrowz/fflate) — zip 压缩 / 解压
- Service Worker — 离线缓存（更新静态文件后需提升 `sw.js` 中的 `CACHE` 版本号）

## 项目结构

```
NoteForge/
├── index.html          # 主页面
├── style.css           # 样式（含液态玻璃主题）
├── app.js              # 应用逻辑
├── sw.js               # Service Worker（离线缓存）
├── manifest.json       # PWA 配置
├── icon.svg            # 应用图标
├── marked.umd.js       # Markdown 解析库
├── highlight.min.js    # 代码高亮库
└── fflate.umd.js       # zip 压缩库
```
