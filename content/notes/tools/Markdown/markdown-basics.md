# 一句话总结
Markdown 是用纯文本写结构化文档的轻量标记语言，笔记、README、文档全靠它。

# 为什么用它
- 纯文本，任何编辑器都能开，永远不锁定格式
- 人裸眼看也基本能读懂
- GitHub、VitePress、大部分博客都原生支持

# 标题
`#` 到 `######`，对应一到六级标题。注意 `#` 后要空格。
```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题

# 文本样式
- 加粗：`**文字**` -> **文字**
- 斜体：`*文字*` -> *文字*
- 删除线：`~~文字~~` -> ~~文字~~
- 行内代码：``代码`` -> `console.log`

# 列表
无序用 `-` 或 `*`，有序用 `1.` `2.`。嵌套就缩进两个空格。
```markdown
- 苹果
- 香蕉
  - 小香蕉（缩进表示嵌套）
```
- 苹果
- 香蕉
  - 小香蕉（缩进表示嵌套）
```markdown
1. 第一步
2. 第二步
3. 第三步
```
1. 第一步
2. 第二步
3. 第三步

# 表格
用 | 分隔列，- 分隔表头和内容：
```markdown
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
| 王五 | 28   | 广州 |
```
| 姓名 | 年龄 | 城市 |
|------|------|------|
| 张三 | 25   | 北京 |
| 李四 | 30   | 上海 |
| 王五 | 28   | 广州 |

对齐控制（加在分隔行里）：
```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:-------:|-------:|
| 内容   |  内容   |   内容 |
```
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:-------:|-------:|
| 内容   |  内容   |   内容 |

# 引用与分割线
- `>` 引用 → 引用块
- `---` 单独一行 → 分割线（用三个 `-`、`*` 或 `_`）
```markdown
> 这是一段引用
> 可以多行
>> 嵌套引用
```
> 这是一段引用
> 可以多行
>> 嵌套引用用 >>

# 链接与图片
- 链接：`[显示文字](https://example.com)`
- 图片：`![替代文字](./img.png)`
区别只在前面多一个 `!`。

# 代码块
用三个反引号包起来，开头标语言名可高亮：
```python
def hello():
    print("Hello, World!")
```

# 任务列表

```markdown
- [ ] 未完成的任务
```
- [x] 已完成的任务

# 转义
```markdown
\* 这不是斜体 \*
\# 这不是标题
```
\*这不是斜体\*

\# 这不是标题

# 实用小贴士
- 一个空行=段落分隔，不加空行视为同一段
- 两个空格+回车=换行（但不如空行直观）
- 列表、标题、代码块前面不要加空格（有序列表的数字后要点+空格）
